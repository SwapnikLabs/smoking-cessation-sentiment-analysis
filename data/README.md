# Data

The original social-media source dataset is not distributed with this repository.

The analysis uses a stratified analytical sample of 10,000 records drawn from a substantially larger source dataset. The sample preserves the source sentiment distribution:

| Sentiment | Records | Percentage |
|---|---:|---:|
| Positive | 4,945 | 49.45% |
| Neutral | 2,626 | 26.26% |
| Negative | 2,429 | 24.29% |
| Total | 10,000 | 100.00% |

Raw social-media records, usernames, URLs, post identifiers, conversation identifiers, reply/quote identifiers, and other direct identifiers are not redistributed through this repository.

The notebook documents the sampling, validation, analysis, and modeling workflow. Results in the repository are presented primarily as aggregate statistics and figures.
